# PS1風 3D探索ゲーム (React + Three.js + WebGL)

## 🎯 プロジェクト概要

本プロジェクトは、**ブラウザ上で動作するPlayStation 1風の3D探索ゲーム**を目指した実験的作品です。
`React` と `@react-three/fiber`（Three.jsのReactバインディング）を使用し、**WebGL上でPS1風の世界表現と操作感**を再現することを目的としています。

もともとは「lainTSX」というWebGL技術によるPlayStationエミュレータ的な試みから着想を得ており、
ブラウザ上で完結するリアルタイム3Dゲームエンジンの構築・拡張を目的としています。

## 🧩 現在の実装状況

### 実装済み機能
- **プレイヤーコントローラー**
  - 3D空間内の自由移動（W/A/S/D + マウス）
  - 第一人称視点カメラ制御（PointerLockControls）
  - カメラ高さ固定（1.6m）
  - スムーズな移動と回転
- **衝突判定システム**
  - AABB（Axis-Aligned Bounding Box）アルゴリズムによる衝突判定
  - 外壁・内壁・装飾ブロックとの衝突検出
  - 回転を考慮した壁の衝突判定
  - プレイヤー半径0.5mの衝突範囲
- **アイテム収集システム**
  - 距離判定（2m以内）によるインタラクション
  - Eキーで収集可能
  - 近接時の視覚的フィードバック（スケールアニメーション）
  - 収集時のスコア加算（+10ポイント/アイテム）
  - 全アイテム収集時のクリアメッセージ表示
- **レンダリング環境**
  - フォグエフェクト（距離15-35）
  - マルチライト設定（Ambient、Directional、Hemisphere）
  - グリッド表示（デバッグ用）
  - アンチエイリアス無効化（PS1風の表現）
- **UIシステム**
  - スコア・アイテム収集数の表示
  - 近接アイテムインジケーター
  - スタート画面・操作方法表示
  - ミッション完了時のエンディング画面
- **フィールド構成**
  - 静的フィールド（外壁・内壁・装飾ブロック）
  - 床・壁のマテリアル設定
  - 5つの収集可能アイテムの配置

### 実装中／今後の課題
1. **ランダムマップ生成**
   - 迷路的なフィールドの自動生成アルゴリズム（例：Recursive Division / Prim法）
2. **内壁（障害物）の自動移動**
   - 一部オブジェクトを周期的に動かし、動的環境を実現
3. **経過時間の表示**
   - プレイ中の経過時間を画面に表示
4. **経過時間の保存**
   - `localStorage` や `sessionStorage` にスコア・時間を一時保存し、再訪時に確認可能に
5. **ゴールオブジェクトのランダム配置**
   - プレイヤーが到達すべきゴールをマップに動的配置

### 予定される追加要素（中長期）
- PS1風ポリゴンレンダリング（頂点スナップによる「ゆがみ」再現）
- 簡易的なシェーダー導入（CRT風フィルター、カラーリミット）
- ミニマップ生成
- 効果音・BGM追加（Web Audio API利用）
- エンディング演出／リスタート画面の実装

|------|------|-----------|------|

| **3D描画エンジン** | Three.js | ^0.180.0 | WebGL描画・3D数学 |
| **React統合** | @react-three/fiber | ^9.4.0 | Three.jsのReactバインディング |

| **データ保存** | sessionStorage / localStorage | - | 一時的スコア・プレイデータ保持（将来実装） |

| **デプロイ** | GitHub Pages / Netlify | - | Webホスティング |

### 技術的詳細

- **3D数学**: Three.jsのVector3を利用した位置・方向計算
- **衝突判定**: AABB（Axis-Aligned Bounding Box）アルゴリズム
- **レンダリング**: WebGL2対応、アンチエイリアス無効化（PS1風の表現）
- **パフォーマンス**: `high-performance` パワープリファレンス設定
- **フレーム更新**: `useFrame` フックによる60FPSの更新ループ

## 🚀 開発・実行方法

### 環境構築

```bash

cd PS1-GAME

# 依存関係のインストール

# 開発サーバーの起動（http://localhost:5173）
npm run dev

# ビルド（デプロイ用）
npm run build

# ビルド結果のプレビュー
npm run preview

# リンター実行
npm run lint
```

### 実行環境要件

- Node.js 18以上
- モダンブラウザ（Chrome、Firefox、Edge、Safari）
- WebGL2対応GPU

## 📝 補足情報

### 実装詳細について

本プロジェクトは、現在 `src/App.jsx` に主要なロジックが統合されています。衝突判定は `checkWallCollision` 関数により、回転を考慮したAABBアルゴリズムで実装されています。プレイヤーの移動は `useFrame` フック内で毎フレーム更新され、カメラの方向ベクトルに基づいた相対的な移動制御を行っています。
